# Dokumentasi HTML Versi 8 (v8) — Fresh & Dynamic MTs Edition

## 📌 Ringkasan Versi
Versi termutakhir yang dibuat berdasarkan instruksi khusus pengguna dengan bantuan mode **`/generative_ui`**. Versi ini memadukan **skema warna Versi 6** (*Oceanic Navy*, *Electric Cyan*, dan *Vibrant Orange*) dengan sentuhan desain yang **jauh lebih segar (*fresh*), dinamis, dan ramah usia santri MTs (12–15 tahun)**.

- **Tipografi**: `Plus Jakarta Sans` dengan rendering antialiased dan kerning tajam.
- **Gaya Tampilan**:
  - *Rounded Pill Shapes* (`border-radius: 9999px` pada badge, tag kategori, dan tombol).
  - *Glassmorphic Sticky Header* (`backdrop-filter: blur(12px)` dengan transparansi halus 94%).
  - *Floating Interactive Badges* dengan bayangan dinamis.
  - *Bento Grid 6 Pilar* yang modern dan interaktif saat disorot kursor (*hover effect*).

   - Pita judul horizontal gradasi cyan dan navy dengan subjudul resmi madrasah.
