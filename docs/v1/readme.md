# Dokumentasi HTML Versi 1 (v1) — Classic Traditional Madrasah

## 📌 Ringkasan Versi
Versi rintisan awal website madrasah yang dibuat untuk memenuhi brief 6 halaman dasar dengan pendekatan desain klasik tradisional bernuansa islami.

---

## 🎨 Identitas Visual & Desain
- **Palet Warna Utama**:
  - Hijau Hutan (*Dark Forest Green*): `#1d4a3c`
  - Hijau Sekunder: `#2f6b57`
  - Emas Islami (*Islamic Gold*): `#c79a2b`
  - Latar Belakang: `#f5f8f6`
  - Teks / Ink: `#17231f`
- **Tipografi**:
  - Judul / Headings: `Literata` (Serif tradisional bernuansa buku dan literatur keislaman)
  - Teks Isi / Body: `Public Sans` (Sans-serif sederhana dan mudah dibaca)
- **Gaya Tampilan**: Bersih, fungsional, minim efek dekoratif, berfokus pada kemudahan akses informasi esensial.

---

## 📂 Struktur Berkas
1. [`index.html`](index.html) — Beranda awal madrasah dengan hero banner, sambutan ringkas, dan daftar program.
2. [`profil.html`](profil.html) — Profil madrasah, sejarah singkat, visi-misi, dan sarana fasilitas.
3. [`akademik.html`](akademik.html) — Informasi jenjang kelas VII–IX, kurikulum, dan kegiatan ekstrakurikuler.
4. [`berita.html`](berita.html) — Kabar kegiatan madrasah, prestasi, dan pengumuman.
5. [`pendaftaran.html`](pendaftaran.html) — Informasi PPDB, jadwal, persyaratan, alur, dan formulir pendaftaran.
6. [`kontak.html`](kontak.html) — Alamat kampus, jam operasional tata usaha, nomor telepon, dan formulir pesan.
7. [`style.css`](style.css) — Lembar gaya CSS dasar.

---

## ⚙️ Catatan Teknis
- Seluruh file HTML telah dilengkapi tag `<meta name="robots" content="noindex">` untuk keamanan staging.
- Gambar menggunakan placeholder responsif dari `https://placehold.co/`.
