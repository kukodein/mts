## 📱 Desain Tabel Responsif (*Responsive Tables System*)
Seluruh tabel riil MTsN Semarang (seperti Kurikulum KBC, Periodisasi Kepemimpinan, Materi Asesmen PMBM, dan Jam Layanan TU) telah dioptimasi untuk sentuhan mobile:
1. **Wadah Geser (`.table-wrap`)**:
   - Memiliki `overflow-x: auto;` dan `-webkit-overflow-scrolling: touch;` untuk kenyamanan navigasi geser di iPhone maupun Android.
   - Dilengkapi scrollbar beraksen cyan yang ramah interaksi.
2. **Indikator Geser Interaktif (`.table-scroll-hint`)**:
   - Menampilkan penanda visual *"↔ Geser ke samping untuk melihat tabel lengkap"* di bagian atas tabel saat dibuka pada tablet (`≤ 992px`) dan ponsel (`≤ 768px`).
   - Disembunyikan otomatis pada monitor desktop (`> 992px`).
3. **Penyusunan Konten Multi-Kolom**:
   - Tabel kurikulum dan periodisasi kepemimpinan memiliki batas `min-width: 580px;` sehingga nama kepala madrasah, periode, maupun mata pelajaran tidak terpotong.
4. **Tabel Ringkas Adaptif (`table.table-compact`)**:
   - Tabel 2-kolom data identitas resmi madrasah dan jam buka loket PTSP menggunakan kelas `.table-compact` agar tetap fit 100% lebar layar tanpa scrollbar samping yang tidak perlu.
